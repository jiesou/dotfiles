# 嘉立创FA零件查找

## Scope

只把 `www.jlcfa.com` 作为机械、电气、自动化和工业零部件的检索与核验来源。这个站点与 `szlcsc.com` 立创商城是独立系统，使用独立的搜索、详情和报价接口；不要套用 LCSC 的券、品牌凑单、历史购买或购物车接口。

默认只读：可以打开搜索结果和商品详情、读取公开或当前登录会话可见的信息、比较候选并生成链接；不要加入购物车、修改数量、分组、结算、提交订单或付款。用户明确要求采购操作时，先说明本 skill 只负责查找，并把候选交给用户确认。

## 查找流程

1. **明确需求**：提取型号、品名、品牌（如有）、关键规格、安装尺寸、数量和可接受替代范围。机械件至少核对尺寸、材料/表面处理、螺纹或孔位、精度和交期；电气件至少核对额定值、接口/接线、安装方式和环境条件。
2. **搜索 FA**：优先使用站内全局搜索或其搜索接口。型号精确匹配优先；无结果时再用品名、系列、规格词和分类组合搜索。不要把 LCSC 的 C 编号当作 FA 型号或详情 ID。
3. **筛选候选**：记录型号、品牌、分类、属性、含税/未税起价、库存、单位、起订量、销售增量、交期、替代品标记和详情页 ID。搜索结果的“起价”只是价格起点，不等于用户数量下的实际单价。
   - **图片优先审查**：审查机械件是否好用的关键证据是图片。至少查看商品实物图、参数图和安装/运动姿态；先确认法兰面、底脚、轴线、孔位、干涉和装配方向，再结合文字规格判断。图片与文字或目标装配关系不一致时，必须标记“待确认”，不能继续宣称兼容。
4. **查图纸和规格表**：遇到尺寸、孔距、安装高度、外形、接口位置或机械兼容问题，必须打开具体候选的详情/系列页，查看“规格表”“参数图”“PDF图档”“下载模型”或“3D模型预览”。以图纸标注和表头定义为准，不能从型号数字或搜索摘要猜尺寸。例如轴承座图中常见 `d` 是轴承内径，`J` 可能是安装孔中心距；`A`、`L`、`H` 等含义必须按该图纸表头确认。
5. **详情核验**：对入选候选打开 `/item/<goodsBizKey>.html` 或 `/serial/<serialBizKey>.html`，读取完整属性、选型变体、价格梯度、税价、交期、MOQ 和递增量；必要时读取相似商品和替代品。关键规格不完整时标记“需看数据手册/图纸”，不凭相似名称宣称兼容。
6. **比较并回报**：按规格符合度、现货/交期、价格、MOQ 和品牌偏好排序。明确区分“完全匹配”“规格部分匹配”“待确认”，并保留每个候选的 FA 详情链接、图纸链接/图片来源和核验时间。

## BOM 查找

对 BOM 逐行搜索，不把整张 BOM 自动导入购物车。每行输出原始需求、搜索词、候选型号、关键规格对照、库存/交期、MOQ、价格口径和差异。型号、规格或数量含糊时列出需要用户确认的问题；NC、已采购和另购项只按用户提供的信息处理，不从 FA 页面推断库存归属。

## 兼容替代规则

只有在电气能力、引脚/接线、封装或安装尺寸、机械接口和环境等级都核对后，才可标为“可替代”。仅因名称相近、同系列、同孔数、同 SOP/螺纹叫法或页面显示“有替代品”不足以证明兼容。无法验证的候选单列为“待确认”，说明缺少的尺寸图、数据手册或应用条件。

## 输出格式

- **候选表**：需求/搜索词、FA 型号、品名、品牌、关键规格、含税起价、库存、MOQ/递增量、交期、详情链接、状态。
- **规格核对表**：逐项列出需求值、页面值、结论（符合/不符/待确认）及证据来源。
- **替代对比表**（如有）：原型号、候选型号、已核对的兼容点、风险和需用户确认项。
- **结论**：推荐候选及排序理由；注明价格是“起价”还是详情页对应数量的价格，数据采集时间，以及未完成的核验。
