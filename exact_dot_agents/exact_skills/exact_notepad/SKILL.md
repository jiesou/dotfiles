# Blog Notepad

## Directory

```
~/Documents/dev/.blog/source/_posts/
```

**Always `git pull` before any work** — this is a public repo.

## New Post / Journal

Use `_template/post.md` as template for all new posts.

### Journal format (daily todos)

Filename: `YYYY.MM.DD.md`

Front matter (use template):
```yaml
title: YYYY.MM.DD
published: false
tags:
  - 日常
categories: 动态
date: {{date}} {{time}}
```

Content starts with unfinished todos as checklist items.

### Regular post format

Front matter:
```yaml
title: {{title}}
published: false
tags:
  - 日常
  - AI
categories: 动态
date: {{date}} {{time}}
```

`abbrlink` is auto-generated by CI — do NOT fill manually.

### Markdown style

- Use **loose line wrapping** (single newline between sentences, not double-space line breaks).
- Inline LaTeX must use `$...$` delimiters. Display math in block uses `$$...$$`. Do NOT use `\(...\)` or `\[...\]`.

### Available tags (use ONLY these)

`AI` `Android` `JavaScript` `Linux` `PVE` `PlatformIO` `Telegram` `TipsTricks` `Web3` `Windows` `云服务` `加密货币` `博客` `好文` `好软件` `学习` `嵌入式` `我的电脑` `技术` `教程` `日常` `游戏` `玩机` `电子`  `程序`

### `#AI` marker convention

New content **should** include `#AI`:
- For a new post: add tag `- AI` in front matter
- For a new todo: `- [ ] #AI something`

## Todos

Todos live in journal files under `~/Documents/dev/.blog/source/_posts/YYYY.MM.DD.md`.

### Check todos

1. Quick journal lookup:
```bash
ls -t ~/Documents/dev/.blog/source/_posts/????.??.??.md | head -1 | xargs cat
```
2. Check last 14 days for ongoing todos by reading more journal files.

### Create todo

1. Determine today's date in `YYYY.MM.DD` format.
2. Check if today's journal exists:
```bash
test -f "~/Documents/dev/.blog/source/_posts/[today YYYY.MM.DD].md" && echo exists
```
3. If exists: append `- [ ] #AI description` to the file.
4. If not: create a new journal from template, then add the todo.
