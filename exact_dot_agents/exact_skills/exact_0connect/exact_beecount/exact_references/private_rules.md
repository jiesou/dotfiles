## 四、判定分叉线

分类判定是**顺序短路**的，命中即返回。顺序如下。

### 收入侧

```
1. 备注含「退款」/「清退」/「小额打款」     → 挂起，等退款配对
2. 备注含「车厘子/椰枣/Patchi/礼盒」        → 亲人
3. 现金红包退回（交易类型以 -退款 结尾且对方为 /） → 其他(不分类) + 退款
4. 闲鱼卖出命中（商品名与买入对得上）        → 跟原买入分类 + 闲鱼
5. 汪世瑶/潘腾轩/杨睿                      → 学校 + AI
6. 家人（爸爸/妈妈/阿山/诸敏/阿明/仁其/吴仁其/外公/甜甜爷爷）
      曾与支出配对成功                     → 亲人 + 报销返款
      否则                                → 亲人
7. 对敲配对成功                            → 学校 + 对敲
8. 同学/实验室/电子集训/班主任/老师/慈职     → 学校
9. 网络计划                                → 学校
10. 网赚（城通/金灏/哔哩哔哩提现/兑换码/邀请码） → 网赚
11. 提现类关键词                            → 平台提现
12. 兜底                                    → 其他(不分类)
```

### 支出侧

```
1. 拼多多（非硬件名）                       → 日用品 + 拼多多
2. 一元流量                                → 折腾 + 电话卡银行卡
3. 与收入配对成功的（被报销）               → 原分类 + 报销返款
4. 周世伍/wang2/博利茶叶（≤60）             → 折腾 + Crypto

6. 小额收钱码（≤5）                        → 折腾 + Crypto
```

## 五、三个双向配对标签

`对敲`
`退款`
`报销返款` 都是**双向**的：收支两边都要打，这样总额能接近配平。

### 对敲

「我替同学买，同学把钱转回来」。

- 支出：备注写明「代付/出借/对敲/还款」，或商品是硬件
- 收入：同学转入
- 配对约束：**同一人**（`NAME` 正则按具体人名比对，不能只按「慈职」这类词）
- 窗口：支出后 14 天内（允许 -2 天容差）
- 金额容差：`max(3, 支出×15%)`
- 备注格式：`戚珂嘉 来回对敲 2025-10-03 出30.00 / 2025-10-03 收32.00`，两边写同一条

### 退款

- 收入：备注含「退款-商品名」
- 配对约束：收入 ≤ 支出×1.3，窗口 -5~120 天（退款可能早于购买）
- 优先商品名重合 ≥2 词，其次商户名一致，再次同额
- 分类跟**原买入**走，两边都打 `退款`
- 一对一只配一次（`REFUND_USED`）
- 配不上的留未匹配

### 报销返款

「家人代付/我先买，家人把钱转回」。

- 收入：家人转入，且与近 30 天内某笔支出对得上（转入 ≥ 支出，差额 ≤3 元或 ≤3%）
- 排除明显馈赠（压岁钱/卷子/成绩/期中期末/外婆奖励）
- 两边都打 `报销返款`
- 备注：`配 YYYY-MM-DD 商户 金额` / `被报销 YYYY-MM-DD 金额`

## 六、几个容易错的点

**不要信支付宝自带的「交易分类」**。它错得很多：三米线自动铅芯标成「餐饮美食」、固态硬盘标成「日用百货」、穿越机桨叶标成「母婴亲子」、MCX 射频连接器被「游戏」误抓。分类只认商品名关键词。

**`待核对` 已全改 `拼多多`**。拼多多账单不含商品名，只能按「多数是日用品」处理。

**红包是兜底，不是首选**。口头的「发口令红包」很多实际是代付或 Crypto，必须先让 Crypto/对敲/学校 认领，剩下才是真红包。

**「一元」= Crypto，不是「一元流量」**。后者是运营商流量包，归电话卡银行卡。

**Hytron 藏在「抚州晴朗广告传媒」名下**。这类广告/传媒/商务咨询公司可能实际是 VPS 或计费代收。

**小主机**：机箱、NUC、准系统、M 卡、PCI-E 转 M.2 延长线、树莓派/香橙派、罗马仕电源，都加 `小主机`。

**游戏**只认 Mojang、Steam、Google Play 内购（rhythnet/Xsolla），不含「游戏鼠标」这类硬件。

**备注要写清楚**。用户提过的商户说明必须写进备注：白马地图、小米云服务、MT管理器、一个木函、狗云、ByteVirt、SakuraFrp、DeepSeek、城通网盘、A6 API 中转站、sub router 中转站、随想中转站、科学上网中转站、Hytron VPS。
