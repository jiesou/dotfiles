# 更新飞达固件

更新飞达固件

6月18日修改

所有送料器均预装固件。以下说明适用于更新新版固件或将自定义固件安装到送料器。

1.

将下载器跳线设置为 3.3v

确保编程器上的3 针接口跳线设置为 3.3V。确保跳线将中间的针脚连接到标有“3.3V”的针脚。飞达主板芯片的逻辑电平工作在 3.3V，因此在使用前应将其设置为 3.3V。

❗

非常重要

下载器默认是5V，请一定按下图调整跳线位置，否则飞达主板可能损坏。

![飞书文档 - 图片](更新飞达固件/img0.png)

2.

将附带的编程器使用数据线连接到您的计算机。

3.

从此处下载最新的固件，或者从[Photon 发布页面下载](<https://github.com/photonfirmware/photon/releases>)特定版本，或者[自行编译](<https://www.yuque.com/lonlypan/td6smc/gk2fcnx6bbbq736z#Sx1Kh>)。
