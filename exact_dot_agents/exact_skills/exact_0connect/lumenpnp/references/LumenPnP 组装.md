# LumenPnP  组装

在开始之前，请先仔细阅读本文文档。

## 开始之前

### 机器方向和术语

在本指南中，我们将用“左、右、前、后、上、下”来指代机器的不同方向和方位。一般来说，这些词语指的是正对机器的典型视角，如下图所示。

![](LumenPnP 组装/image.png)

我们还将提到将机器“放回原位”。这是 LumenPnP 的一项功能，可以通过将机器前后抬起，然后让其直立在后脚上。这种方向对于将东西安装到工作平台上以及底部不限连接到主板非常有帮助。

![](LumenPnP 组装/image-1.png)

> 每次将机器放回原位前，请确保将 X 龙门架一直推到机器后部，以防止 X 龙门架在放回原位时自由落体，和反向驱动 Y 步进电机驱动器（这可能会损坏主板）。

![](LumenPnP 组装/image-2.png)

### 存储和放置

确保将 LumenPnP 存放在阴凉干燥的环境中。请勿长时间暴露在温暖的环境中或阳光直射下。请放置在平坦、稳定的平台上使用。

**LumenPnP 应在光照一致的房间内使用。机器执行的机器视觉操作可能会受到环境光照变化的影响，因此请确保在整个校准和操作过程中保持光照一致。**

### 时间

预计组装大约需要**90分钟**。

### 你需要

- 用于组装的干净、光滑、平整的桌面
- 一台计算机
- 能够插入三个高带宽 USB-A 端口 - 您的计算机需要与控制机器的usb数据线以及两个usb摄像头源进行通信。

> **USB 集线器/ 扩展器**
>
> 有的使用外部 USB 集线器联接，这个方法可能可行，有的仍然需要链接到电脑上的不同usb口，这个具体取决于你的电脑硬件，如果你发现异常，请尝试使用电脑上的usb口或者更换usb集线器。
