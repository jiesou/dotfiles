# 真空元件检测（气压传感器）

真空元件检测（气压传感器）

6月27日修改

使用 LumenPnP 拾取零件时，务必确认零件已成功拾取。虽然底部摄像头也能进行视觉确认，但使用 LumenPnP 的真空传感器可以更快地检测拾取是否成功，无需先将零件移动到底部摄像头前进行检测。由于底部摄像头也会检查零件（虽然速度稍慢些），但您可以放心地禁用真空零件检测功能，依然可以进行稳定贴片作业。

✏️

v4.0.1版本有关于真空检测的教程，v4.1.0官方却删除，但配置文件中默认启用了该功能。所以这里补上教程。

✏️

禁用真空检测

根据多人使用反馈，和必要性，这里建议禁用真空检测（实际我们可以通过底部相机识别也能完成检测功能，真空检测只是一个加分项，不是必须的）

如果您想禁用此功能，只需在Machine Setup > Nozzle Tips > ReferenceNozzleTip N## > Part detection tab > Measurement Method > None相应的喷嘴设置中将“测量方法”设置为“None”即可。请务必在继续操作前Apply保存您的设置和配置。

真空部件检测的工作原理

当零件被拾取时，它会封闭吸嘴口，导致气动管路内的真空压力升高。真空传感器会测量这种压力变化，OpenPnP 利用这些数据来判断零件是否被成功拾取。在吸嘴尖端被覆盖的情况下，如果真空传感器的读数落在真空范围的低值和高值之间，OpenPnP 则认为零件已被“拾取”。
