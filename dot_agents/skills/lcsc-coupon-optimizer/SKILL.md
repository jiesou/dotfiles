# LCSC 满减凑单优化

## 前置条件

1. 用户需求来源于：BOM 表 / 采购清单 / 购物车中已有的元件。购物车中已有元件是硬需求，不可删减。
2. 根据以上列出"硬需求清单"。

## 凑单流程

### 第一步：硬需求清单加入购物车

如果硬需求清单中的产品还未加入购物车，先全部加入。

### 第二步：逐厂家优化（满减券）

对每个支持优惠券的厂家（参见 `references/coupons.md`），依次执行以下子步骤：

#### 2.1 检查现状

计算该厂家现有产品总价是否已满足满减门槛：
- 满16减15：总价 16.00~16.09 为"完全满足"，16.00~16.29 为"基本满足"
- 满21减20：总价 21.00~21.09 为"完全满足"，21.00~21.29 为"基本满足"

若已"基本满足"，该厂家处理完成，进入下一个厂家。

#### 2.2 调整硬需求产品数量

尝试在该厂家中，通过调整现有硬需求产品的购买数量来达到满减条件。

注意：大多数产品有最少起购量和购买倍数限制。将"最少不可分割金额"（min_qty × unit_price）视为伪产品单价来考虑。

使用 `scripts/optimize_quantities.py` 进行暴力遍历：

```bash
python3 scripts/optimize_quantities.py '<json>' <threshold> [max_above]
```

JSON 格式：
```json
[{"name":"品名","unit_price":0.35,"min_qty":5,"qty_multiple":5,"current_qty":0,"min_extra":0}]
```

- `unit_price`: 单品单价
- `min_qty`: 最少起购数量 (默认 1)
- `qty_multiple`: 必须以 N 的倍数购买 (默认 1)
- `current_qty`: 当前购物车中已有数量 (默认 0)
- `min_extra`: 允许在原基础上最少额外增加的数量 (默认 0)

脚本输出多个较优方案（按总价升序），从中选取最合适的。

#### 2.3 从该厂家寻找凑单品

如果仅靠调整硬需求产品数量仍无法"完全满足"（差距 > 0.10 元），则：

1. 进入该厂家的品牌页
2. 点击排序按钮（`#searchListButton`），按"最少不可分割金额"升序排列
3. 找到能填补价格缺口的产品

#### 2.4 兼容替换硬需求产品

如果硬需求产品的价格太过特殊，导致无论如何都无法凑到合理金额，则考虑兼容替换。

**允许的兼容替换**：
- 物理外形尺寸不同（如按钮开关尾部长度差 2mm，价格差 0.20 元）
- 电气参数不同：更便宜但略差的平替（向下兼容）
- 电气参数完全向下兼容的更好替代（向上兼容）
- 封装略有不一致（如 0805 换 0603）

**不允许的兼容替换**：
- 封装不一致（如 0603 换 0805）
- 产品用途不一致

价格完全相同、仅尺寸略不同的产品，利用价差调整数量来凑单。

兼容替换的产品单独列出表格，标注原产品和替换产品，供用户最终核实。

### 第三步：全场凑包邮（满 9.9 元）

处理完所有厂家优惠券后，进行全场凑单确保满 9.9 元包邮。

#### 3.1 计算差额

计算距离 9.9 元还差多少钱。

#### 3.2 第一级：支持优惠券的其他厂家

优先从硬需求清单里考虑其他厂家的替换品。绝大多数芯片、连接器都有多家厂家供货。

如果某硬需求产品只有一个厂家提供，跳过该项。

将支持满减券的厂家（`references/coupons.md`）视为第一级其他厂家，按第二步的凑单流程重新凑一轮，这样每个厂家至少能增加一元以上。

#### 3.3 第二级：不支持优惠券的厂家

若距离 9.9 元仍有差距，从不支持满减券的厂家购买通用物料凑单
这些可以考虑：
- 低功耗 LDO
- 各种 MOS 管
- 小封装的电平转换，74HCXXX 缓冲器、功能芯片等
- 各种封装的晶振，8Mhz 12Mhz 40Mhz
- 冷门连接器
这些不用考虑，太常见已经有很多了：
- 100nF 电容
- 10K 电阻
- 卧贴 USB-C 连接器（立的可以考虑）
- TF卡 连接器

核心目标是总价尽可能接近 9.9 元，最好是精确的 9.9 或者 10.0 元。

## 凑单品选取原则

- 优先按硬需求清单购买，每件都必须考虑备损数量，不能只按 BOM 精确数量购买
- 有意义的凑单品：经典尺寸按钮开关、8MHz 晶振、低功耗 LDO
- 无意义的凑单品：莫名其妙尺寸的电流采样电阻等
- 利用同型号不同尺寸版本的价差，通过调整数量来精确凑单
- 在该厂家中找到能够精确填充价格差距的产品后，结合实际意义选择合适的那一款

## 输出格式

最终输出包含：
1. **硬需求清单表格**：品名、规格、厂家、数量、单价、小计
2. **各厂家凑单方案表格**（每个厂家一张）：产品、数量、单价、小计，厂家总价，优惠券使用情况
3. **兼容替换对比表格**（如有）：原产品 → 替换产品，替换理由，需用户确认
4. **全场凑包邮明细**：补充产品列表与金额
5. **总览**：原价总计、优惠券减免、实付金额
